# Offline-to-Online Personalized LLM Algorithms

This is an Overleaf-ready technical note for the five validated ideas in
`directions/ideas/personalized_llm_training_v2_prose_enhanced/`.

## Build

Upload this directory to Overleaf and set `main.tex` as the main document, or
compile locally:

```bash
tectonic main.tex --keep-logs --keep-intermediates
```

The note is intentionally separate from the repository's existing `main.tex`.
It specifies proposed workflows and algorithms; it does not claim completed
experiments or measured improvements.
